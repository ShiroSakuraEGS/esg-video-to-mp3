## 1. 範圍

- 本版包含：靜態前端、本機轉 MP3、佇列、位元率、裁切、繁中／可選英文、Pages 工作流程、NOTICE。
- 本版不包含：任何 URL 抓取或平台下載、後端、帳號、多執行緒 ffmpeg、執行期 CDN 載入核心。

## 2. 功能規格

### F-01 檔案輸入與佇列
- 描述：拖放或 `<input type="file" multiple>`。檔案加入佇列，轉換時一次處理一個以降低記憶體。
- 輸入／輸出：本機 File 物件；不讀取遠端 URL。
- 錯誤：單檔超過 256 MB → 拒絕並顯示過大訊息；80–256 MB 顯示記憶體警告但仍可嘗試。
- 驗收：Given 兩個本機測試檔 When 一次選入 Then 佇列出現兩列且可全部轉換。

### F-02 格式
- 描述：接受常見副檔名（mp4／mov／webm／mkv／m4a／wav 等）。音訊優先走 Web Audio；影片與失敗案例走單執行緒 ffmpeg.wasm。
- 錯誤：兩者皆失敗 →「不支援的格式」。

### F-03 位元率
- 描述：全域選 128／192／320 kbps，套用到後續轉換。
- 驗收：輸出為 MP3，探測到位元率接近所選值（允許編碼開銷造成的偏差）。

### F-04 裁切
- 描述：每列可填起點／終點（秒）。空白＝整段。終點須大於起點。
- 驗收：5 秒測試檔裁切 1–3 秒，輸出長度約 2 秒。

### F-05 進度與下載
- 描述：顯示大小、長度（能讀取時）、進度、完成後下載。下載檔名為原名改副檔名 `.mp3`。

### F-06 聲明與非功能（不做下載器）
- 描述：頁面固定隱私與著作權聲明。介面沒有 URL 欄位，程式也不請求第三方媒體網址。

### F-07–F-09 介面
- 繁體中文預設；可切 English（記在 localStorage）。360px 寬仍可操作主要按鈕。

## 3. 非功能需求

| 項目 | 要求 |
|---|---|
| 託管 | 可放在 GitHub Pages；不依賴自訂 COOP/COEP |
| 隱私 | 檔案不出裝置；無上傳 API |
| 執行期網路 | 不從 CDN 載入 ffmpeg／lamejs（已內嵌）。一般瀏覽器對字型或擴充元件的請求不在本專案控制範圍。 |
| 語言 | 繁體中文預設，可選英語 |
| 瀏覽器 | 以本機 Chromium／Chrome 測試為準；Safari 未在本次自動化中作為必過項 |

## 4. 資料與內容

- 不儲存使用者媒體。測試用短檔由本機 ffmpeg 以 `lavfi` 合成，僅供測試，不必提交大媒體檔。
